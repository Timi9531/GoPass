# GoPass
Simple password generator written in go

Usage:

`-c` Amount of password generations\
`-d` Amount of digits used in password (default 3)\
`-s` Amount of special characters used in password (default 1)\
`-u` Amount of uppercase letters used in password (default 5)\
`-l` Amount of lowercase letters used in password (default 5)
